# Поиск по составу в каталоге сайта «Золотое Яблоко»

Весь этот проект сгенерирован через Claude.  
Основная цель — находить в каталоге ЗЯ товары, где в составе есть ретинол или другой ингредиент.

Приложение: https://stels-cs.github.io/gold-apple/

Поиск осуществляется прямо в браузере, бэкенда нет, поэтому фронтенд скачивает ~30 МБ поисковых индексов на 188 тысяч продуктов.
База продуктов актуальна на 25 сентября 2026 года, выгружена с сайта ЗЯ.
