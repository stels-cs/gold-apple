# Каталог товаров (веб-приложение)

Одностраничное приложение на React + Mantine: фильтры (бренд, тип продукта, категории, состав —
включающие и исключающие) и список товаров с сортировкой по цене. Бэкенда нет, все данные — статические
файлы в `public/data`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (можно отдавать любым статическим хостингом)
```

## Подготовка данных

`npm run build-data` выгружает данные из PostgreSQL (`DATABASE_URL`, по умолчанию
`postgres://goldapple:goldapple@localhost:54321/goldapple`) в `public/data`:

| Файл                                            | Содержимое                                                                |
|-------------------------------------------------|---------------------------------------------------------------------------|
| `price.bin`, `brand.bin`, `type.bin`            | `Int32Array` по товарам; товары отсортированы по цене (по возрастанию)    |
| `breadcrumbs.bin`, `ingredients.bin`            | списки id на товар: длина + zigzag-дельты в varint (порядок сохраняется)  |
| `brands/types/breadcrumbs/ingredients.json`     | справочники колонками `ids / names / counts [/ orig]`, по убыванию частоты |
| `shards/N.json`                                 | тексты товаров (название, `description_title`, `url`) по 1000 штук        |
| `meta.json`                                     | число товаров, размер шарда                                               |

Названия ингредиентов — русские (`name_ru`), если перевод есть; оригинал хранится в `orig` и тоже участвует в поиске.
Категории показываются полным путём (`волосы › шампуни`).

## Как это работает

- Фильтрация — линейный проход по типизированным массивам (десятки мс на 189 тыс. товаров).
  Разные поля — «И». Включающие фильтры бренда/типа — «любой из», категорий/ингредиентов — «все сразу».
  Исключающие — «ни одного из».
- Поиск значений в фильтрах — [MiniSearch](https://lucaong.github.io/minisearch/) в Web Worker
  (префиксный, с упрощённым русским стеммингом и ранжированием по популярности значения).
- Тексты страницы результатов подгружаются из шардов; так как товары отсортированы по цене,
  нужные шарды идут подряд.
- Состояние (фильтры, сортировка, страница) хранится в `location.hash`, так что ссылкой можно поделиться.
